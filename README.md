# Celesa

Hold a key, talk, let go: clean text in your own voice appears wherever you type. Everything runs on your Mac.

**[Download Celesa 0.8.1 for Mac](https://github.com/ThenaAI/celesa-releases/releases/download/v0.8.1/Celesa-0.8.1.dmg)** (macOS 14 or later, Apple Silicon)

1. Open the file and drag Celesa onto Applications.
2. Open Celesa. If macOS says it "could not verify" it, click Done, then go to System Settings > Privacy & Security and click **Open Anyway**. You only do this once: later updates install from inside the app.
3. Allow Microphone and Accessibility when asked. Hold Right Option and talk.

## What's new in 0.8.1

- **Setup now asks for the camera** (Mac): a new last step, "Help Celesa read your lips", takes one agreement and the camera permission. Then Celesa learns your lips while you dictate, and the video stays on your Mac. "Not now" skips it. If you set up Celesa before this, you see just this step once after updating

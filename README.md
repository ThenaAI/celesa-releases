# Celesa

Hold a key, talk, let go: clean text in your own voice appears wherever you type. Everything runs on your Mac.

**[Download Celesa 0.7.0 for Mac](https://github.com/ThenaAI/celesa-releases/releases/download/v0.7.0/Celesa-0.7.0.dmg)** (macOS 14 or later, Apple Silicon)

1. Open the file and drag Celesa onto Applications.
2. Open Celesa. If macOS says it "could not verify" it, click Done, then go to System Settings > Privacy & Security and click **Open Anyway**. You only do this once: later updates install from inside the app.
3. Allow Microphone and Accessibility when asked. Hold Right Option and talk.

## What's new in 0.7.0

- **Voice lock** (Mac and Windows): Settings > Voice lock > Set up my voice. Read four short sentences and Celesa only types your voice; other people talking near you are ignored, and if nobody but them spoke you see "Not your voice". Relaxed, Balanced or Strict sensitivity. The voiceprint is a short list of numbers on your computer, refined by every dictation you keep; no recording is stored. Uses an on-device speaker model (CAM++, about 30 MB, downloaded once at setup). If the model is missing, Celesa types everything as before
- Releases are signed with a new "Celesa Developer" certificate. If you have 0.6.0, download this version by hand once from https://github.com/ThenaAI/celesa-releases and allow Microphone and Accessibility again. Later updates install from inside the app as before
- Built-in examples and test data no longer contain real names or messages
- Email mode signs off with "Best," and lets you add your own name in the email mode file
